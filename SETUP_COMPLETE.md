## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Open in Browser
```
http://localhost:3000
```

### 4. Customize Your Information

Open these files and update with your details:
- `src/components/sections/Hero.tsx` - Name & title
- `src/components/sections/About.tsx` - Bio
- `src/components/sections/Experience.tsx` - Work experience
- `src/components/sections/Skills.tsx` - Your skills
- `src/components/sections/Projects.tsx` - Your projects
- `src/app/layout.tsx` - Meta information

### 5. Deploy
```bash
npm run build
npm run start
```
