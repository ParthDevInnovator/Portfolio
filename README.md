# Parth Makwana

Personal developer portfolio built using Next.js, TypeScript, Tailwind CSS, and Framer Motion.

The goal of this portfolio was simple:
create something clean, modern, interactive, and visually strong without overcomplicating the experience.

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui

---

## Running Locally

Clone the project:

```bash
git clone https://github.com/ParthDevInnovator/portfolio.git
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

## About the Portfolio

I wanted this portfolio to feel modern and smooth while still keeping the focus on projects and engineering work.

A lot of the design inspiration comes from modern startup websites and developer portfolios with:
- dark UI
- subtle motion
- clean typography
- layered layouts
- minimal but strong visuals

The site includes:
- animated hero section
- project showcase
- experience timeline
- skills section
- responsive layouts
- smooth interactions
